# Mirrorcore Project Purpose

Mirrorcore is a local-first, modular Python CLI system for persistent reasoning, troubleshooting, decision support, and investigation workflows.

Primary goals:
- model user reasoning patterns, preferences, and troubleshooting behavior
- preserve context locally through SQLite-backed storage
- support deterministic investigation and follow-up workflows
- remain usable offline by default
- keep user data private and under explicit user control

Mirrorcore is not:
- a simulated person
- a sentient identity
- a cloud-first assistant
- a generic chatbot framework

Project priorities:
1. correctness
2. determinism where possible
3. minimal safe changes
4. local-first storage and behavior
5. explainable workflows
6. backwards compatibility for working CLI flows
