# Project Purpose

Mirrorcore is a local-first reasoning assistant that models user thinking patterns for practical assistance.

## Core Mission
- Provide personalized troubleshooting and decision support
- Learn from user interactions while maintaining privacy
- Operate entirely on local systems with optional cloud enhancements

## Boundaries
- Models reasoning patterns, not identity
- Maintains clear tool/utility boundaries
- No consciousness or sentience claims
- User consent required for all data collection
